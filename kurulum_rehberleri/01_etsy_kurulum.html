Teşekkür E-postası

✅ Başlamadan Önce Kontrol Listesi

  • Make.com veya Zapier hesabı açık
  • OpenAI API anahtarı hazır (platform.openai.com/api-keys)
  • Gmail hesabına erişiminiz var
  • Etsy Seller hesabınız aktif
  • Google Sheets'te "Siparişler" adlı bir sayfa oluşturdunuz

⚙️ Make.com Kurulumu

1

Şablonu Import Edin

Make.com'da sol menüden Scenarios'a gidin → sağ üstteki ··· (üç nokta) menüsünden "Import Blueprint" seçin → make_blueprints/01_etsy_siparis_tesekur_email.json dosyasını yükleyin.

2

Webhook URL'ini Kopyalayın

İlk modül (Webhook) üzerine tıklayın → "Copy address to clipboard" butonuna basın. Bu URL'i bir yere not edin, Etsy'de kullanacaksınız.

3

Etsy Webhook Ayarlayın

Etsy Developer Portal → Applications → Webhook ekleyin → URL olarak kopyaladığınız Make.com adresini yapıştırın. Event: RECEIPT_ACCEPTED seçin.

4

OpenAI Bağlantısı Kurun

3. modüle (OpenAI) tıklayın → "Add" butonuyla yeni bağlantı ekleyin → API anahtarınızı girin → "Save".

5

Gmail Bağlantısı Kurun

4. modüle (Gmail) tıklayın → Google hesabınızla OAuth ile giriş yapın. "From" alanına mağaza adınızı ve e-posta adresinizi girin.

6

Google Sheets Ayarlayın

5. modüle (Google Sheets) tıklayın → Spreadsheet ID'nizi girin. Sheets'inizde şu sütunları oluşturun: Tarih | Sipariş No | Müşteri Adı | E-posta | Ürün | Tutar | E-posta Gönderildi

7

Test Edin ve Aktif Edin

Sağ alt köşedeki "Run once" butonuna basın → Etsy'den test siparişi gönderin → Her şey çalışıyorsa senaryoyu ON konumuna getirin.

✅ Test İpucu Make.com'da test için sağ alttaki "Run once" modunu kullanın. Etsy'den gerçek sipariş beklemeden webhook'u manuel olarak tetikleyebilirsiniz.
⚠️ OpenAI Maliyeti GPT-4o Mini çok ucuz — her e-posta yaklaşık $0.001 (0.1 kuruş) tutar. 5$ ile 5.000+ e-posta gönderebilirsiniz.

⚡ Zapier ile Kurulum

1

Yeni Zap Oluşturun

Zapier Dashboard → "Create Zap" → Trigger olarak Etsy → New Order seçin.

2

OpenAI Adımını Ekleyin

Action → OpenAI → Send Chat Message. zapier_templates/01_etsy_siparis_tesekur_email.json dosyasındaki mesaj şablonunu kopyalayın.

3

Gmail Adımını Ekleyin

Action → Gmail → Send Email. To: Etsy'den gelen e-posta, Subject ve Body alanlarını JSON'daki gibi doldurun.

4

Sheets Adımını Ekleyin (Opsiyonel)

Action → Google Sheets → Create Row. JSON'daki config alanlarını kullanarak sütunları eşleştirin.
