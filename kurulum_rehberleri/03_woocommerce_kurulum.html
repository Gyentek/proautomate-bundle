ŞABLON 03 · KURULUM REHBERİ

🛒 WooCommerce Sipariş → Notion CRM

Gelen her siparişi Notion veritabanına ekler, AI ile müşteri analizi yapar ve Slack'e bildirim gönderir.

📋 Notion Veritabanı Hazırlama

Notion'da iki veritabanı oluşturun:

Siparişler Veritabanı Sütunlar: Sipariş No (Title), Müşteri (Text), E-posta (Email), Telefon (Phone), Tutar (Number), Para Birimi (Select), Durum (Select), Ürünler (Text), Sipariş Tarihi (Date), Ülke (Select), Ödeme Yöntemi (Select), WC Linki (URL)

⚙️ WooCommerce API Anahtarı Oluşturma

1

WooCommerce Ayarlarına Gidin

WordPress Admin → WooCommerce → Settings → Advanced → REST API

2

Yeni API Anahtarı Oluşturun

"Add key" butonuna tıklayın → Description: "Make.com Entegrasyonu" → Permissions: "Read/Write" → "Generate API Key"

3

Anahtarları Kaydedin

Consumer Key ve Consumer Secret'i kopyalayıp güvenli bir yere yapıştırın. Bir daha gösterilmez!

⚠️ Önemli Uyarı Consumer Key ve Consumer Secret sadece bir kez gösterilir. Sayfayı kapatmadan önce mutlaka kopyalayın!

⚙️ Make.com Kurulumu

1

Blueprint Import

Make.com → Import Blueprint → make_blueprints/03_woocommerce_notion.json

2

WooCommerce Bağlayın

1. modül → Site URL, Consumer Key, Consumer Secret girin.

3

Notion Entegrasyonu Kurun

notion.so/my-integrations → "New integration" → Token'ı kopyalayın → Make.com'da Notion modüllerine bağlayın. Veritabanlarınızı entegrasyonla paylaşmayı unutmayın (Share > Invite).

4

Veritabanı ID'lerini Girin

Notion veritabanı URL'sinden ID'yi kopyalayın. Format: notion.so/DATABASE_ID?v=...

5

OpenAI + Slack Bağlayın

Kalan modüllere hesaplarınızı bağlayın. Slack kanalını ayarlayın.

✅ Test İpucu WooCommerce'den küçük bir test siparişi verin ve Notion'da otomatik oluştuğunu kontrol edin. Slack'e bildirim geldiğini de doğrulayın.
