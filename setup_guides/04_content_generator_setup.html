TEMPLATE 04 · SETUP GUIDE

✍️ ChatGPT Auto Content Generator

Turns a single keyword into a blog post, social media content, and an email newsletter. Automatically distributes to WordPress, Mailchimp, and Notion.

🎯 What Gets Generated?

📝 Blog Post

SEO-optimized title, meta description, and 800+ words of HTML content. Uploaded to WordPress as a draft.

📱 Social Media Content

Instagram caption + hashtags, a Twitter tweet (280 characters), and a professional LinkedIn post.

📧 Email Newsletter

Mailchimp campaign draft: subject line, preview text, and HTML email content.

📊 Google Sheets Queue

Create a "Content Queue" sheet in your spreadsheet. Columns: Topic | Keywords | Language | Target_Audience | Tone | Category | Status | Completion_Date | Blog_Title | WP_Link | Notion_ID

💡 How to Use Set the "Status" column to "To Generate". Every morning the system picks up these rows, generates the content, and updates them to "✅ Generated".

⚙️ Make.com Setup

1

Import the Blueprint

Make.com → Import Blueprint → make_blueprints/04_chatgpt_content_generator.json

2

Connect Google Sheets

Modules 1 and 7 → enter your Spreadsheet ID → select the "Content Queue" sheet.

3

Connect OpenAI (GPT-4o)

2nd module → enter your API key. This template uses GPT-4o (for higher-quality content).

4

Connect WordPress

4th module → enter your Site URL → WordPress Admin → Users → Profile → Application Passwords → create a new password → enter it in Make.com.

5

Connect Mailchimp

5th module → connect with your Mailchimp account → select your Audience (List) ID.

6

Connect Notion

6th module → set up the Notion integration (see the previous guide) → enter your content database ID.

7

Set the Schedule

Set it to run every day at 6:00 AM. It generates up to 5 pieces of content per day.

⚡ Free Scaling Tip To generate more content, increase the "limit: 5" value. Keep the OpenAI cost in mind, though — GPT-4o spends roughly $0.05-0.10 per piece of content.
