GETTING STARTED GUIDE

Welcome! 🎉

This bundle includes 4 ready-made automation templates. Each one is configured separately for Make.com and Zapier. No technical skills needed — just follow the instructions.

⏱️ Estimated Setup Time About 20-45 minutes per automation. The first setup may take a little time; the rest will be much faster.

✅ Before You Begin

You'll need a few basic accounts for all the templates. Get the following ready:

Required Accounts

  • A Make.com or Zapier account The free plan works fine. Sign up at make.com or zapier.com.
  • An OpenAI API key Create one at platform.openai.com/api-keys. With $5 of credit you can send hundreds of emails.
  • A Gmail account Your existing Gmail is enough. Required for the email templates.

Additional Accounts by Template

  • Template 01 (Etsy Email): Etsy Seller account + Google Sheets
  • Template 02 (Social Media): Buffer + Slack (optional) + Google Sheets
  • Template 03 (WooCommerce): WooCommerce store + Notion + Slack
  • Template 04 (Content Generator): WordPress + Mailchimp + Notion + Google Sheets

⚙️ Which Platform?

Your templates are ready for both platforms. Choose the one that suits you best:

Make.com

✓ Supports JSON import

❓ Frequently Asked Questions


How do I import JSON into Make.com?

On the Scenarios page, open the "..." menu in the top right and select "Import Blueprint", then upload the JSON file.

Is the OpenAI API free?

New accounts get $5 of free credit. GPT-4o Mini is very cheap, so you can make thousands of requests with that credit.

Can I modify the templates?

Yes! The JSON files are fully open and editable. You can add or remove steps to fit your own needs.
