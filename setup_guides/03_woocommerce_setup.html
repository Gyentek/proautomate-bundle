TEMPLATE 03 · SETUP GUIDE

🛒 WooCommerce Order → Notion CRM

Adds every incoming order to a Notion database, runs an AI customer analysis, and sends a Slack notification.

📋 Preparing the Notion Databases

Create two databases in Notion:

Orders Database Columns: Order No (Title), Customer (Text), Email (Email), Phone (Phone), Amount (Number), Currency (Select), Status (Select), Products (Text), Order Date (Date), Country (Select), Payment Method (Select), WC Link (URL)

⚙️ Creating a WooCommerce API Key

1

Go to WooCommerce Settings

WordPress Admin → WooCommerce → Settings → Advanced → REST API

2

Create a New API Key

Click the "Add key" button → Description: "Make.com Integration" → Permissions: "Read/Write" → "Generate API Key"

3

Save the Keys

Copy the Consumer Key and Consumer Secret and paste them somewhere safe. They won't be shown again!

⚠️ Important Warning The Consumer Key and Consumer Secret are shown only once. Be sure to copy them before closing the page!

⚙️ Make.com Setup

1

Import the Blueprint

Make.com → Import Blueprint → make_blueprints/03_woocommerce_notion.json

2

Connect WooCommerce

1st module → enter the Site URL, Consumer Key, and Consumer Secret.

3

Set Up the Notion Integration

notion.so/my-integrations → "New integration" → copy the token → connect it to the Notion modules in Make.com. Don't forget to share your databases with the integration (Share > Invite).

4

Enter the Database IDs

Copy the ID from your Notion database URL. Format: notion.so/DATABASE_ID?v=...

5

Connect OpenAI + Slack

Connect your accounts to the remaining modules. Set the Slack channel.

✅ Testing Tip Place a small test order in WooCommerce and check that it's created automatically in Notion. Also confirm that the notification arrives in Slack.
