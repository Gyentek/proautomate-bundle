✅ Pre-Setup Checklist

  • Make.com or Zapier account is open
  • OpenAI API key is ready (platform.openai.com/api-keys)
  • You have access to a Gmail account
  • Your Etsy Seller account is active
  • You've created a sheet named "Orders" in Google Sheets

⚙️ Make.com Setup

1

Import the Template

In Make.com, go to Scenarios in the left menu → open the ··· (three dots) menu in the top right → select "Import Blueprint" → upload the make_blueprints/01_etsy_order_thankyou_email.json file.

2

Copy the Webhook URL

Click on the first module (Webhook) → press the "Copy address to clipboard" button. Note this URL down somewhere — you'll use it in Etsy.

3

Set Up the Etsy Webhook

Etsy Developer Portal → Applications → add a Webhook → paste the Make.com address you copied as the URL. Choose the event: RECEIPT_ACCEPTED.

4

Set Up the OpenAI Connection

Click on the 3rd module (OpenAI) → add a new connection with the "Add" button → enter your API key → "Save".

5

Set Up the Gmail Connection

Click on the 4th module (Gmail) → sign in with your Google account via OAuth. Enter your store name and email address in the "From" field.

6

Configure Google Sheets

Click on the 5th module (Google Sheets) → enter your Spreadsheet ID. Create these columns in your sheet: Date | Order No | Customer Name | Email | Product | Amount | Email Sent

7

Test and Activate

Press the "Run once" button in the bottom-right corner → send a test order from Etsy → if everything works, switch the scenario to ON.

🔧 Customization Variables

VariableWhat You Need to Do
GMAIL_ACCOUNTConnect via Gmail OAuth
SENDER_NAMEEnter your store name (e.g., "Anna's Workshop")
SENDER_EMAILEnter your sender email address
GOOGLE_SHEETS_IDThe long ID between /d/ and /edit in the Sheets URL
✅ Testing Tip Use the "Run once" mode in the bottom right of Make.com to test. You can trigger the webhook manually without waiting for a real Etsy order.
⚠️ OpenAI Cost GPT-4o Mini is very cheap — each email costs about $0.001 (a tenth of a cent). With $5 you can send 5,000+ emails.

⚡ Setup with Zapier

1

Create a New Zap

Zapier Dashboard → "Create Zap" → choose Etsy → New Order as the trigger.

2

Add the OpenAI Step

Action → OpenAI → Send Chat Message. Copy the message template from the zapier_templates/01_etsy_order_thankyou_email.json file.

3

Add the Gmail Step

Action → Gmail → Send Email. To: the email from Etsy; fill in the Subject and Body fields as shown in the JSON.

4

Add the Sheets Step (Optional)

Action → Google Sheets → Create Row. Map the columns using the config fields in the JSON.
