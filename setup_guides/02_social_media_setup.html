📱 Social Media Auto Content Planner

Reads your content calendar in Google Sheets, generates platform-specific content with ChatGPT, and schedules posts to Instagram, Twitter/X, and LinkedIn via Buffer.

📊 Prepare Your Google Sheets Template

Create a sheet named "Content Calendar" in your spreadsheet and add the following columns:

Column NameDescriptionExample
TopicContent topicMinimalist home decor trends
Target_AudienceDefine your audienceAges 25-40, home decor enthusiasts
ToneCommunication toneFriendly, inspiring
Hashtag_CountHow many hashtags15
Publish_DateISO format date2024-12-25T10:00:00
StatusStatus (do not change)Ready
Scheduled_DateFilled automatically(leave blank)
Buffer_IDFilled automatically(leave blank)
💡 Tip: The Status Column Set the Status column to "Ready" for the rows you want processed. The system picks up these rows, processes them, and updates them to "✅ Scheduled".

⚙️ Make.com Setup

1

Import the Blueprint

Make.com → Scenarios → Import Blueprint → upload the make_blueprints/02_social_media_planner.json file.

2

Connect Google Sheets

1st module (Google Sheets) → connect with your Google account → enter your Spreadsheet ID → Sheet name: "Content Calendar".

3

Connect OpenAI

2nd module (OpenAI) → enter your API key. Model: gpt-4o-mini (cheap and fast).

4

Connect Buffer

Create a free account at Buffer.com → connect the Buffer module in Make.com via OAuth → select your Instagram, Twitter, and LinkedIn profiles.

5

Connect Slack (Optional)

Last module (Slack) → connect your Slack workspace → Channel: #social-media or any channel you prefer.

6

Set the Schedule

Scenario Settings → Scheduling → set it to run every day at 8:00 AM.
